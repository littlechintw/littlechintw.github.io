About

關於我，以及這個網站

嘿，我是小群，網路上通常叫 littlechin。我是個攝影師，也是個程式設計師，目前在一間企業擔任 QA Engineer，負責軟體品質與測試。 除了熱愛創造新事物，也喜歡在城市與程式之間穿梭，希望讓更多人能夠看見世界，也讓更多人用得到我做出來的工具。

我在做什麼

工作上，我從軟體測試開始。大學時在 HP Inc. 擔任 Software Testing Intern，畢業後回到同一間公司擔任 Software / System Engineer， 之後轉為專職的 QA Engineer。測試讓我習慣從使用者的角度把產品走過一遍，這個習慣也一路帶進我自己的 side project。

2021 年夏天，我參加了行政院公共數位創新空間 PDIS 的 Ray 5.0 見習計畫，和組員一起用使用者訪談、Wireframe、Prototype 的方式改善政府網站的數位服務體驗。 那兩個月的過程寫成了一系列文章，收在#PDIS。

資安與社群

資安是我在大學時期投入最多時間的領域。從 2019 年起我連續四屆參加臺灣好厲駭高階資安人才培訓計畫並結業，也上過 AIS3 新型態資安實務主題課程的數位鑑識組。 2020 到 2023 年，我以學研攻擊手的身分參與行政院國家資通安全網路攻防演練，近年則在教育體系資安攻防演練擔任攻防檢測員。

社群方面，我在國立臺北大學成立並帶領 Google Developer Student Clubs（GDSC NTPU），現在則以社師的身分回去陪學弟妹。 SITCON 學生計算機年會、COSCUP 開源人年會、HITCON 台灣駭客年會、g0v 台灣零時政府與 Google Developer Group 的活動裡，常常可以在紀錄組或攝影組看到我拿著相機。

攝影

相機是我參與社群的方式之一。這幾年我幫許多技術研討會做活動紀錄，也在上岸音樂節擔任相手。 對我來說，拍照和寫程式很像，都是在替別人保留一個好用、好看的切面。

我做過的工具

這個網站的子網域住著幾個我自己寫、自己在用的工具，全部免費，原始碼也都放在 GitHub：

  • 音樂祭行程規劃 ：幫你規劃音樂祭行程，安排想看的表演與時間衝突。
  • 廁所地圖 ：快速找到全台附近的公共廁所。
  • 工具箱 ：日常與開發都會用到的小工具集合。
  • 短網址服務 ：貼上網址或文字，產生簡短連結方便分享。

這個網站

littlechin.tw 是我的個人網站。首頁放的是我的經歷與作品，文章區則用來記錄開發筆記、資安學習、社群活動與攝影心得。 過去寫在 Medium 上的文章也陸續搬了過來，之後的新文章會直接發表在這裡。

網站本身是用 Astro 與 Tailwind CSS 做的純靜態網站，部署在 GitHub Pages 上， 原始碼公開在 GitHub。 網站使用 Google Analytics 了解流量，詳細說明請看隱私權政策。
