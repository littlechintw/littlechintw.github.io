PDIS Ray 5.0 上工紀錄（四 + 總結）

Ray 5.0 的最後階段：用 Vue.js 與 Vuetify 把 High-Fi Prototype 的註冊流程寫成可操作的網頁、做 SUS 量表驗證，以及兩個月見習的完整回顧與心得。

發佈於 2021年9月2日 · 約 6 分鐘，2,286 字
  • #PDIS
  • #UX
  • #實習

介紹一下這個計畫，這是由行政院公共數位創新空間（PDIS）所開設的大專生公部門實習計畫，全稱是 Rescue Action by Youth .gov，是由我們與國發會及相關部會一起協作，來改善政府網站數位服務體驗，而這個計畫在今年（2021）來到了第五屆，所以在這個計畫通常會說我們是 Ray5 的見習生。

在這個階段，我們將所有蒐集到的回饋與意見集結，並著手 High-Fi Prototype 的部分，期間除了使用 Figma 作為主要的開發平台外，我與組員算是走了兩個支線，他們使用 Figma 開發 Prototype，我則是利用撰寫程式碼的方式將其中的一個流程實作出來，其中運用的網頁框架是 Vue.js，我也套用了 Vuetify 這個 Material Design Framework 來讓這個網站有個比較好的皮膚，我也因為這個專案讓我更加了解 CSS 的使用，真的是覺得非常的有趣。

在以前，我很常直接使用 Vuetify 內建的排版去搭配而已，很少操作 CSS 的部分，因為這次的經驗真的讓我對此有很多的進步，至少從以往的簡單排版，晉升到這次有撰寫很多 CSS 的 code 在 <style /> 這個 tag 了！

完成之後，我們馬上著手使用者訪談的部分，很快的我們連繫了一些訪談者，最終我們與 4 位訪談者進行訪談，而這次我們也對我們的新網站作了 SUS 量表，讓使用者可以在使用後對這個網站進行評分，也驗證我們的改良後是否讓這個網站有更好的呈現。

而最後就是我們最期待的環節，也就是成果發表的階段，當天我們向所有人發表我們的結案成果，並且在現場讓大家能夠操作我們的 Prototype，而且也讓大家操作我利用程式碼所做出的註冊流程網頁模擬，除了讓部會人員操作，甚至唐鳳 AU 也實際操作了我所做的網頁，而且也被抓到跑版了 XD

我們在當天的攤位呈現

當天與部會人員的合照（我是最左邊的那位）

不過在這天的時候，我感覺我在表達的能力有大大提升，在講簡報的時候竟然感覺較為之前更加順暢地說完了全部，真的有些意外，在與測試者測試時，我也很快而且很清楚的把內容說的還不錯，真的太神奇了，或許是當天有腦波的加持吧（誤）

最後，我想要來個總結，敘述在這兩個月的見習內容、心得以及收穫（也讓我填在這個計劃要交的行政文件哈哈哈）

最一開始，經過了第一次見面會，我們分配好了組別與確定專案執行的內容，在這天，我與組員們也討論了日後的工作型態為何，我們對於工作的習慣都蠻相同的，大家希望的時間與假日盡量不工作的情況都是大家所共同的，而且我們也在此決定日後要一起工作，於是我們在每天都會安排時間上去，每天也藉由我開設 Google Meet 連結來視訊，一開始討論每天的工作內容，之後就一起進行工作內容，而且這個模式也維持了兩個月都沒有改變！

首先階段是要進行議題的探索，我們打開網頁，並且嘗試了一些使用者可能會進行的操作，嘗試了解這個網頁所想要帶給使用者甚麼樣的事情，最後我們也都辦了帳號想要看看更多內容，我們也在這個時候發現了一些初步問題，之後我們對這個網頁做競品分析，也就是與這個網頁性質接近的網站比較，在這個階段我們也了解很多有趣的功能，並且這些功能讓我們在日後製作 Prototype 的時候有更多的想法。

之後我們開始了使用者訪談，詢問使用者在使用原本的網站是否有遇到甚麼問題，也在此了解使用者的使用流程，畫出了 User Journey Map，我們也將問題統整，並且將我們想要詢問網頁負責機關的問題加入清單內，在之後與機關訪談時，我們也利用這些問題來確定未來所改善的方向，來讓整個網站的定位不只是能滿足使用者，也要能與機關有連結。

做完了很多的研究之後，我們就開始了製作 Wireframe 的環節，在此時，我們先是製作了 A 與 B 版的內容，其中 A 版是保留原本網站的大多元素，有種墨守成規的感覺，B 版則是天馬行空，我們能夠加上任何我們想要做的內容，而不需考慮太多，在這之後，我們也與訪談者訪談在操作完這兩個版本後的想法，我們也發現許多的使用者非常喜歡 B 版的內容，不過也有對 A 版的部分內容感到喜歡，於是我們就根據這些內容來製作出我們的 C 版，也就是 A、B 版的融合，也形成了我們的 Low-Fi Prototype，在這個階段我們是給參與 Ray 計畫的其他夥伴一起測試，在這裡我們也是獲得許多的意見，將這些問題融合後，我們便著手製作 High-Fi Prototype 的完成品了！

到最後的部分，我們為這個網站配色，並且也與機關確認許多的網站問題，來為我們的最後階段作品有個明確的方向，而我也利用撰寫程式碼的方式來驗證這些設計都是足以使用程式碼來製作出，完成後，我們進入訪談階段，讓訪談者來操作這個新的網頁，並且告訴我們是否有遇到什麼問題，也為這個網站作出 SUS 的分數，讓我們驗證我們在這兩個月的內容都是有成果的！

見習後，我覺得我真的體會到了工作的勞累，開始懂上班族們的辛苦，真的是非常的厲害，原來為這個社會驅動的每個人都是付出很多的；在這次的見習，其實因為疫情的關係，很常見面會是以線上方式進行，希望之後沒有疫情的時候還有機會能與大家有更多的接觸！

雖然時常覺得疲憊，不過我認為在參與這個見習後還是讓我學習到很多，我們在工作時，其實都非常融洽，大家都能很放鬆的表達自己的想法，雖然其實一開始的時候沒有太多勇氣告訴組員問題，不過後來都會鼓起勇氣將自己心中所想的問題提出，雖然有時候講出來的時候發現講的內容可能不對，但大家都很樂意接納各種問題，最後也有針對一些內容作出改善，我覺得最重要的就是要說出來了吧！而我也因為這個見習讓我知道要如何善用工具，我們每天都在異地工作，網路是唯一讓我們有所連結的工具，我們也藉由許多的工具讓大家能夠在這份工作中發揮更大的效率，我想這也會讓我在日後於專題或是其他機會，將我們協作的方式帶入，為每個工作與製作都能有很高的效率。

最後簡短來說，我覺得真的非常推薦這個計畫給未來想要從事 UI / UX 的工程師與設計師，這是個很棒的機會能夠接觸政府的網頁，尤其政府網頁的使用者也是相當多，所做的服務如果有機會落地，那麼自己在此的設計也是很有機會讓更多人接觸的！雖然我偏向工程師的面向，不過在參與這個計劃後，我認為以工程師的角度與思維，也能為這個專案做出很多的貢獻，真的不用太多擔心，我相信每個人都能為專案做出一分貢獻的！
